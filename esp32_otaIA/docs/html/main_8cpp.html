Detailed Description

ESP32 + DHT22 + LEDs: OTA e IA (regresión logística) para gestión del dispositivo.

  • Lee temperatura y humedad del DHT22.
  • La regresión logística calcula la probabilidad de condición de riesgo. Riesgo -> LED rojo y OTA bloqueado. Normal -> LED verde y OTA permitido.
  • La IA diagnostica fallas del sensor: falla de cable -> LED rojo parpadeando; falla de sensor -> LED rojo parpadeando rápido. Con cualquier falla el OTA se aplaza.
  • Periódicamente consulta al servidor si hay firmware nuevo y lo instala (LED amarillo).
